# CHICHEJ

Sistema inteligente de dispensación automatizada de chicha mediante aplicación móvil, Firebase e Internet de las Cosas.

## Estructura

- `app/`: aplicación Flutter para clientes, invitados y administrador.
- `esp32/`: firmware del dispensador inteligente.
- `firebase/`: reglas, índices y documentación de Firebase.

## Estado actual

- Aplicación Flutter funcionando en Android.
- Identificador Android: `com.chichej.app`.
- Firebase Authentication operativo.
- Proyecto Firebase: `chichej-2026`.
- Inicio de sesión con cuentas existentes funcionando.
- Firmware funcional recuperado como sketch principal.
- Integración Flutter → Firestore → ESP32 aún en desarrollo.
